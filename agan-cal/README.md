# agan-cal - 阿甘计算器

阿甘计算器 - 一个基于 DLL 的 CAD 计算器工具。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 阿甘工具 > 阿甘计算器 | `c:ag` | 启动阿甘计算器 |

## 源文件

| 文件 | 说明 |
|------|------|
| `agan-cal.lsp` | 主程序入口，初始化历史记录文件 |
| `agancal` | 计算器核心模块 |
| `AganCal.dll` | 计算器 .NET DLL |
| `AganCal18.dll` | 计算器 .NET DLL (兼容版本) |

## 依赖

- `base`

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I agan-cal
```
