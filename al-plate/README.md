# al-plate - 铝板展开

铝板构件展开绘制工具，根据铝板轮廓自动生成展开图。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 铝板 > 铝板配置 | `(al-plate:setup)` | 打开铝板参数配置对话框 |
| 铝板 > 铝构展开 | `(al-plate:draw1)` | 选择多段线生成展开图 |

## 配置项

| 配置名 | 默认值 | 说明 |
|--------|--------|------|
| `al-plate:al-layer` | A-铝板 | 铝构件框线图层 |
| `al-plate:thikness-layer` | A-板厚线 | 铝构件厚线图层 |
| `al-plate:thikness` | 0.5 | 铝板厚度值 |
| `al-plate:length` | 200 | 铝构件绘制长度 |
| `al-plate:turned` | 1 | 是否转角构件 (0:非转角, 1:一端转角, 2:两端转角) |
| `al-plate:symmetry` | 1 | 是否对称 |

## 源文件

| 文件 | 说明 |
|------|------|
| `al-plate.lsp` | 主程序，包含配置、展开计算和绘图功能 |

## 依赖

- `base`

## 使用说明

1. 在图层 `A-铝板` 上绘制铝板轮廓多段线
2. 在图层 `A-板厚线` 上绘制板厚辅助线
3. 运行 "铝构展开" 命令，选择轮廓线
4. 程序自动计算各段长度并生成展开图
