# align-array - 对齐排列

单体对齐、等距排列插件，支持图框排版，提供 DCL 对话框界面。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 创意绘图 > 对齐排列 | `(align-array:align-array)` | 打开对齐排列对话框 |

## 功能说明

- **单体对齐**: 水平/垂直/双向对齐，支持 9 点基点选择
- **等距排列**: 水平/垂直等距排列
- **图框块排列**: 按图框块进行排列
- **矩形框排列**: 按矩形外框进行排列
- **手工选择**: 手动框选图纸内容进行排列
- **自动识别**: 自动识别图框进行排列
- **阵列功能**: 重排阵列和复制阵列
- **插入图框**: 在矩形框中插入指定图框块

## 源文件

| 文件 | 说明 |
|------|------|
| `align-array.lsp` | 主程序（约 1000 行），包含完整对齐排列功能 |

## 依赖

- `base`

## 使用说明

1. 运行命令打开 DCL 对话框
2. 选择对齐方式（水平/垂直/双向）
3. 选择对象类型（单体/图框块/矩形框/手工选择/自动识别）
4. 设置间距参数
5. 确认执行
