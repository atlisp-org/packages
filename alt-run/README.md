# alt-run - ALTRun 快速启动

ALTRun 是一款快速启动软件，精致简洁的操作界面、智能匹配、快速响应。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 外部程序 > ALTRun | `(alt-run:open)` | 启动 ALTRun 程序 |

## 源文件

| 文件 | 说明 |
|------|------|
| `alt-run.lsp` | 主程序，自动下载并启动 ALTRun |

## 依赖

- `base`

## 配置

无配置项。首次运行会自动从网络下载 `ALTRun.zip` 到 `bin` 目录。

## 安装

在 CAD 命令行执行：
```
@I alt-run
```
