# at-3d - @lisp 3D 相关工具

3D 曲面、实体相关工具包，提供曲面剖切功能。

## 菜单命令

| 菜单路径 | 命令 | 说明 |
|---------|------|------|
| 3D相关 → 选点剖切 | `(at-3d:slice-by-pts)` | 将曲面用过多个点的平面剖切 |
| 3D相关 → 路径剖切 | `(at-3d:slice-by-route)` | 将曲面用曲线路径剖切 |

## 函数

| 函数 | 说明 |
|------|------|
| `at-3d:slice-by-pts` | 选择曲面和控制点，按选定方式（平行XY/YZ/ZX/垂直导向线）进行剖切 |
| `at-3d:slice-by-route` | 选择曲面和路径曲线，按分段数沿路径进行剖切 |

## 剖切方式

在执行剖切时，弹出多选对话框，可选择以下剖切方式（可多选）：

1. 平行于 XY 面
2. 平行于 YZ 面
3. 平行于 ZX 面
4. 垂直于导向线

## 依赖

- `base`

## 安装

在 CAD 命令行执行：

```
@I at-3d
```

或：

```
(@:package-install "at-3d")
```
