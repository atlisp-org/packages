# at-dim - @lisp标注

标注斜率、线长、坐标标注、剖切符号、弧长等分等综合标注工具包。

## 菜单

在 @lisp 面板的"标注"菜单下注册以下功能：

| 菜单项 | 调用函数 | 说明 |
|--------|----------|------|
| 标注设置 | `@dim:setup` | 打开配置对话框，设置图层、箭头、精度、单位、比例等 |
| 选线标斜率 | `at-dim:menu-dim-slope` | 选择直线或多段线，自动标注斜率（1:N格式） |
| 坐标标注 | `at-dim:menu-zbbz` | 标注选定点的坐标及标高，支持多重引线或文本+多段线两种模式 |
| 设置比例 | `at-dim:set-scale` | 快速设置当前标注比例 |
| 标等分弧长 | `at-dim:menu-dimarc-div` | 选择圆弧并输入等分数，自动标注每段弧长 |
| 剖切符号 | `at-dim:cutting-symbol` | 绘制剖切符号，支持向视和剖视两种模式，自动编号 |
| 标注求和 | `@dim:sum-dim` | 选择多个标注，计算并显示标注值之和 |
| 标注面积 | `at-dim:area` | 选择闭合多段线，标注面积值（m²） |
| 尺寸偏差 | `at-dim:make-deviation` | 对选中尺寸统一增减指定偏差值 |
| 尺寸原值 | `at-dim:true-value` | 清除尺寸文字覆盖，显示标注的实际测量值 |

## 配置项

通过 `@dim:setup` 或 `(@:get-config '@dim:xxx)` / `(@:set-config '@dim:xxx value)` 访问：

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `@dim:layer` | `"dim-coor"` | 标注图层名，为空时使用当前图层 |
| `@dim:arrow` | `""` | 箭头样式 |
| `@dim:units` | `3` | 标注精度（小数位数） |
| `@dim:text-units` | `"m"` | 标注文字单位，`m`=米，`mm`=毫米 |
| `@dim:draw-units` | `"mm"` | 绘图单位，`m`=米，`mm`=毫米 |
| `@dim:scale` | `100.0` | 标注比例 |
| `@dim:textheight` | `2.5` | 标注文字高度 |
| `@dim:coordinate-position` | `0` | 坐标标注位置，`0`=自动，`1`=手动 |
| `@dim:coordinate-type` | `0` | 坐标标注图元类型，`0`=多重引线，`1`=文本和多段线 |
| `@dim:prefix` | `"XY"` | 坐标前缀，可选 `XY`、`AB`、`NE` |
| `@dim:elevation` | `1` | 是否标注标高，`0`=不标注，`1`=标注 |
| `@dim:switch-xy` | `1` | XY坐标是否互换，`0`=不交换，`1`=交换 |
| `@dim:dimarc-gap` | `1000` | 弧长标注到弧线的距离 |

## 使用示例

### 斜率标注
1. 点击菜单"选线标斜率"或输入 `at-dim:menu-dim-slope`
2. 选择要标注的直线或多段线
3. 自动在每段中点标注 `1:N` 格式斜率

### 坐标标注
1. 点击菜单"坐标标注"
2. 选择基准点
3. 选择要标注的点
4. 自动标注 X、Y 坐标及标高（如配置开启）

### 弧长等分标注
1. 点击菜单"标等分弧长"
2. 选择圆弧
3. 输入等分数量
4. 自动标注每段弧长

### 剖切符号
1. 点击菜单"剖切符号"
2. 指定起始点
3. 鼠标左击放置符号，右键切换向视/剖视模式
4. 按 `S` 键可设置文字高度和箭头大小
5. 输入字母可切换编号
