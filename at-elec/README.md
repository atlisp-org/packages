# @lisp建筑电气

建筑电气设计工具：回路编号、电缆标注、负荷统计、设备统计与插入等。

## 依赖

- `at-pm` 包

## 安装

在CAD命令行中执行：
```lisp
@I at-elec
```

或：
```lisp
(@:package-install "at-elec")
```
