# at-lab - @试验室

试验性代码集中营，包含特定功能和尝鲜功能。

## 源文件

| 文件 | 说明 |
|------|------|
| `at-lab.lsp` | 主程序入口 |
| `menus` | 菜单定义 |
| `named-first-layout-from-filename` | 布局命名 |
| `attxyz2csv` | 属性坐标导出CSV |
| `rec-tube` | 矩形管 |
| `dyn-adjust` | 动态调整 |
| `summary-data` | 数据汇总 |
| `stat` | 统计 |
| `array` | 阵列 |
| `z-value` | Z值操作 |
| `split-text` | 文字拆分 |
| `pvp` | PVP工具 |
| `board` | 板工具 |
| `stat-number-inline` | 行内数字统计 |
| `get-cross-from-2layer` | 获取两图层交叉点 |
| `center-content` | 内容居中 |

## 依赖

- `base`
