# at-nlp - 自然语言交互

与 CAD 进行中文自然语言交互，如选择、修改颜色等。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| @试验室 > 关于NLP | `(@nlp:about)` | 显示 NLP 功能说明 |

## 功能说明

支持自然语言指令，如：
- "选择所有坐标大于0,0的图元"
- "选择所有半径等于5的圆"
- "修改直径为200"
- "修改为绿色"

## 源文件

| 文件 | 说明 |
|------|------|
| `at-nlp.lsp` | 主程序，包含语料解析和代码生成功能 |
| `corpus` | 语料库 |
| `corpus-tangent` | 天正语料库 |

## 依赖

- `base`

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I at-nlp
```
