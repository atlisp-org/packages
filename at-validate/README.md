# @lisp包验证工具

运行时包验证工具：括号匹配检查、未定义函数检测、重复定义检测、依赖检查等。

## 依赖

- `base` 包

## 安装

在CAD命令行中执行：
```lisp
@I at-validate
```

或：
```lisp
(@:package-install "at-validate")
```
