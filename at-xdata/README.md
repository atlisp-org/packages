# at-xdata - @lisp 扩展数据管理

查看和修改 DWG 图元中的扩展数据（XData）。

## 菜单命令

| 菜单路径 | 命令 | 说明 |
|---------|------|------|
| 扩展数据管理 → 查询扩展数据 | `(at-xdata:browser)` | 依次浏览图元的扩展数据 |
| 扩展数据管理 → 配置过滤器 | `(at-xdata:set-filter)` | 设置扩展数据 APPID 过滤器 |

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `@xdata:filter` | `*` | 扩展数据过滤器，用于过滤不需要的 APPID |

## 函数

| 函数 | 说明 |
|------|------|
| `at-xdata:browser` | 弹出对话框依次显示所选图元的扩展数据，支持上一个/下一个/缩放操作 |
| `at-xdata:set-filter` | 扫描全图获取所有 APPID，让用户多选设置过滤器 |

## 使用说明

1. 执行 `查询扩展数据`，框选含有扩展数据的图元
2. 在对话框中可浏览每个图元的 APPID 和数据内容
3. 使用 `Prev`/`Next` 切换图元，`ZoomExt` 缩放到当前图元
4. 若未找到图元，可通过 `配置过滤器` 调整 APPID 过滤条件

## 依赖

- `base`

## 安装

在 CAD 命令行执行：

```
@I at-xdata
```

或：

```
(@:package-install "at-xdata")
```
