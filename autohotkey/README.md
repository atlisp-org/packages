# autohotkey - AutoHotKey

AutoHotKey (AHK) 是简易而功能强大的热键脚本语言，可记录键盘、鼠标、游戏摇杆动作。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 外部程序 > AutoHotKey | `(autohotkey:open)` | 启动 AutoHotKey 程序 |

## 源文件

| 文件 | 说明 |
|------|------|
| `autohotkey.lsp` | 主程序，自动下载并启动 AutoHotKey |

## 依赖

- `base`

## 配置

无配置项。首次运行会自动从网络下载 `AutoHotKey.zip` 到 `bin` 目录。

## 安装

在 CAD 命令行执行：
```
@I autohotkey
```
