# block-update - 块更新

从指定文件夹中更新最新图块的定义。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 块操作 > 更新块 | `(block-update:update)` | 从目录更新图块定义 |
| 块操作 > 设置更新块 | `(block-update:setup)` | 设置更新块的目录和数量 |

## 快捷命令

| 命令 | 说明 |
|------|------|
| `RB` | 执行块更新 |
| `RBB` | 打开块更新设置 |

## 配置项

| 配置名 | 默认值 | 说明 |
|--------|--------|------|
| `block-update:path` | D:\block | 要更新块的目录 |
| `block-update:number` | 5 | 要更新块的数量 |

## 源文件

| 文件 | 说明 |
|------|------|
| `block-update.lsp` | 主程序，包含更新和设置功能 |

## 依赖

- `base`

## 使用说明

1. 将需要更新的 .dwg 块文件放入指定目录
2. 运行 "设置更新块" 配置目录和数量
3. 运行 "更新块" 执行更新（按修改时间排序）

## 注意事项

- 要更新的图块文件不能在 CAD 中处于打开状态
