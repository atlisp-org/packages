# block-view - BlockView 块预览

块预览工具，提供图块的可视化预览界面。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| Block > BlockView | `C:BlockView` | 打开块预览对话框 |

## 源文件

| 文件 | 说明 |
|------|------|
| `block-view.lsp` | 主程序入口 |
| `BlockView` | BlockView 核心模块 |
| `BlockView.odcl` | OpenDCL 对话框定义文件 |

## 依赖

- `opendcl`

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I block-view
```
