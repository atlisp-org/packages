# cmd-ext - 命令扩展

扩展命令行，支持汉字/拼音命令执行 CAD 基本绘图操作。

## 功能说明

支持 200+ 汉字命令映射，如：圆、直线、矩形、复制、移动、镜像、旋转、缩放、修剪、延伸、偏移、阵列、填充、标注、图层、块定义、文字、打印等。

常用命令示例：

| 汉字命令 | CAD命令 | 汉字命令 | CAD命令 |
|----------|---------|----------|---------|
| 圆 | CIRCLE | 直线 | LINE |
| 复制 | COPY | 移动 | MOVE |
| 镜像 | MIRROR | 旋转 | ROTATE |
| 修剪 | TRIM | 延伸 | EXTRUDE |
| 偏移 | OFFSET | 阵列 | ARRAY |
| 填充 | HATCH | 图层 | LAYER |
| 块定义 | BLOCK | 插入块 | INSERT |
| 多行文本 | MTEXT | 打印 | PLOT |
| 缩放 | ZOOM | 删除 | ERASE |

## 源文件

| 文件 | 说明 |
|------|------|
| `cmd-ext.lsp` | 汉字命令映射表 |

## 依赖

- `base`

## 配置

无配置项。加载后自动注册所有汉字命令。

## 安装

在 CAD 命令行执行：
```
@I cmd-ext
```
