# composing — 排版（功能扩展计划）

## 已知问题 / 扩展点

| 优先级 | 事项 | 说明 |
|--------|------|------|
| P0 | 无 | 当前无阻塞问题 |
| P1 | FFD 启发式优化 | 当前用「已放件右上角候选点 + 左下优先」启发式，未做天际线（skyline）/ 剩余空间（MaxRects）优化，利用率对窄长件不够优 |
| P1 | 板材利用率统计 | `ai-nest` 未返回利用率/剩余面积，可按需补充 |
| P2 | 交互选择件来源扩展 | `unest` 目前从 TEXT/MTEXT 提取「宽 高 数量」或手输，可扩展为读取图框/闭合多段线外轮廓作为件尺寸 |
| P2 | 余料/切缝线绘制 | `ai-nest-draw` 未画切割线、余料标记，可按需补充 |

## 与 iMini 的差异（全能材料排版 mini_unest）

- **算法**：iMini 为 C++ exe，内置 7 种排版算法（含多种启发式与优化策略）；本包为纯 AutoLISP 的 FFD（First-Fit Decreasing）单算法。
- **输出**：iMini 输出加工文件/刀路；本包输出每件的摆放坐标 `((版次 (件号 x y 宽 高 旋转) ...) ...)`，供 CAD 内直接绘制或二次处理。
- **入口**：本包额外提供 AI 无交互入口 `composing:ai-nest` / `composing:ai-nest-draw`，供 MCP agent 直接调用。
- **依赖**：本包仅依赖 `base`，无外部可执行文件。
