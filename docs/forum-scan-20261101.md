## 3. 代码分析

35 帖成功抓取正文，其中只有 5 帖能看到 `defun`：

| 帖子 | defun 数 | 可复用性 |
|---|---|---|
| 15283 对象均布与对齐 | 8 | 商业工具，明确不公开完整源码 |
| 82692 拓扑多边形算法 | 5 | 正文只给辅助函数，核心在登录后 |
| 85342 Block→Lisp | 4 | 生成器是 VLX，正文只有 `gxl-Blk-Check` 片段 |
| 106891 局部放大 | 2 | 主程序完整，但依赖大量 `gxl-*` 辅助函数 |
| 171203 文字合并 | 1 | 完整，但 `at-text` 已覆盖 |

代码质量观察（对可复用片段）：

- 大量依赖作者私有 `gxl-*` 函数库，直接复制到本项目会缺依赖；
- 很少写 `*error*` 清理（图层锁定/UCS/临时实体残留）；
- 交互式 `grread`/`getpoint` 入口多，不适合 MCP/AI 直接调用；
- 附件型源码（VLX/FAS）不可直接读，需按功能重写。

## 5. 本轮落地

新增 `packages/at-stat/hatch-area.lsp`：

| 函数 | 说明 |
|---|---|
| `at-stat:hatch-area-data` | 按填充图案汇总面积/数量，可传换算系数 |
| `at-stat:ai-hatch-area` | AI 入口，返回 `((图案 面积 数量) ...)` |
| `at-stat:ai-hatch-area-table` | AI 入口，汇总并绘制 `ACAD_TABLE` |
| `at-stat:hatch-area` | 交互：选填充 → 系数 → 插入点 |

CAD 实测：两个 100×100 矩形分别填 `ANSI31` / `SOLID` →
`(("SOLID" 10000.0 1) ("ANSI31" 10000.0 1))`；表格生成 `ACAD_TABLE`。

新增 `packages/at-layer/layer-create.lsp`：

| 函数 | 说明 |
|---|---|
| `@layer:ai-layers-from-file` | 从 TXT 逐行读图层名并建层（跳过空行/`#`/`;`） |
| `@layer:ai-layer-from-text` | 以 TEXT/MTEXT 内容为图层名建层 |
| `@layer:layers-from-file` / `@layer:layer-from-text` | 交互入口 |

图层名清洗：`< > / \ " : ; ? * | , =` 逐位替换为 `_`。CAD 实测：
`WALL`、`A/B`、`COLUMN` + 前缀 `X-` → `X-WALL`、`X-A_B`、`X-COLUMN`；
文字 `MEETING` → 图层 `MEETING`。
