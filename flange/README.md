# 法兰工具

法兰绘图工具。从参数表读取数据绘制法兰，支持多种 DN 规格。

## 菜单命令

| 菜单组 | 命令名称 | 调用函数 | 说明 |
|--------|----------|----------|------|
| 法兰工具 | 绘制法兰 | `(flange:draw)` | 从参数表选择法兰规格并绘制 |

## 函数列表

| 函数名 | 参数 | 说明 |
|--------|------|------|
| `flange:make` | `pt-c DN Dw Dd Ds n t1` | 绘制法兰图形 |
| `flange:draw` | 无 | 从参数表选择并绘制法兰 |

## flange:make 参数说明

| 参数 | 说明 |
|------|------|
| `pt-c` | 中心点坐标 |
| `DN` | 公称直径（内径） |
| `Dw` | 外径 |
| `Dd` | 螺丝间距 |
| `Ds` | 螺丝直径 |
| `n` | 螺丝个数 |
| `t1` | 厚度 |
