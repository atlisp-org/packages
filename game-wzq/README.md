# game-wzq - 五子棋

CAD 内五子棋游戏，AI 水平很低，谁都能赢。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 游戏 > 五子棋 | `(game-wzq:start)` | 开始五子棋游戏 |

## 源文件

| 文件 | 说明 |
|------|------|
| `game-wzq.lsp` | 主程序入口 |
| `wzq.fas` | 五子棋编译模块 |
| `wzq.zelx` | 五子棋加密模块 |

## 依赖

- `base`（隐含）

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I game-wzq
```
