# landscape-plants - 园林植物设计

XXLH 园林植物设计插件。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 园林绿化 > 园林植物 | `(landscape-plants:xxlh)` | 加载 XXLH 园林植物插件 |

## 源文件

| 文件 | 说明 |
|------|------|
| `landscape-plants.lsp` | 主程序入口 |
| `xxlh.vlx` | XXLH 园林植物 VLX 模块 |

## 依赖

- `base`

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I landscape-plants
```
