# list-rec-wxh - 统计矩形宽高

列出正交矩形宽高表，支持倒角/圆角矩形、缺角矩形的统计。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 统计 > 矩形统计表 | `(list-rec-wxh:draw)` | 统计矩形宽高并绘制列表 |
| 统计 > 矩形分色 | `(list-rec-wxh:stat)` | 按宽高统计并用颜色区分 |

## 快捷命令

| 命令 | 说明 |
|------|------|
| `TJJX` | 绘制矩形统计表 |

## 源文件

| 文件 | 说明 |
|------|------|
| `list-rec-wxh.lsp` | 主程序，包含宽高计算、统计和绘图功能 |

## 依赖

- `base`

## 使用说明

1. **矩形统计表**: 选择 4-8 顶点的多段线矩形，在指定位置绘制宽高统计表
2. **矩形分色**: 选择矩形后自动按宽高分组并用不同颜色标记
