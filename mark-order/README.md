# mark-order - 字串编号

在特定文本上方显示编号，支持单行文本、多行文本、属性值、块内文本、天正门窗。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| Demo > Number by string | `(mark-order:main (mark-order:findtext))` | 为匹配文本添加编号 |

## 配置项

| 配置名 | 默认值 | 说明 |
|--------|--------|------|
| `mark-order:matchs` | *M*,*C* | 欲匹配的文字模式 |
| `mark-order:notmatchs` | *MM*,*CC*,*%C* | 不能匹配的文字模式 |

## 源文件

| 文件 | 说明 |
|------|------|
| `mark-order.lsp` | 主程序，包含文本匹配和编号生成功能 |

## 依赖

- `base`

## 使用说明

1. 运行命令后选择图中对象
2. 程序自动筛选匹配的文本
3. 在每个匹配文本上方生成红色编号 (1#, 2#, ...)
