# prefabricated-building - 装配式建筑

装配式建筑设计工具集。

## 源文件

| 文件 | 说明 |
|------|------|
| `prefabricated-building.lsp` | 主程序入口 |
| `steel-in-foundation` | 基础钢筋模块 |
| `gen-detail` | 详图生成模块 |
| `beam` | 梁构件模块 |
| `slab` | 板构件模块 |
| `menus` | 菜单定义 |

## 依赖

- `base`

## 配置

无配置项。

## 安装

在 CAD 命令行执行：
```
@I prefabricated-building
```
