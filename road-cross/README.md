# 十字路口生成器

十字路口生成器及道路修补工具。支持道路绘制、画线补路、参数设定等功能。

## 菜单命令

| 菜单组 | 命令名称 | 调用函数 | 快捷键 | 说明 |
|--------|----------|----------|--------|------|
| 十字路口 | 绘制道路1 | `(road-cross:rd)` | rd | 道路宽由鼠标1,2点决定 |
| 十字路口 | 绘制道路2 | `(road-cross:srd)` | srd | 道路宽由键盘输入 |
| 十字路口 | 画线补路 | `(road-cross:sld)` | sld | 在既有道路间补一条路 |
| 十字路口 | 容差设定 | `(road-cross:std)` | std | 设置倒圆角和误差值 |
| 十字路口 | 列道路宽 | `(road-cross:prd)` | prd | 列出找到的道路宽度值 |
| 十字路口 | 帮助 | `(road-cross:help)` | - | 显示帮助信息 |

## 函数列表

| 函数名 | 参数 | 说明 |
|--------|------|------|
| `road-cross:rd` | 无 | 绘制道路（鼠标决定宽度） |
| `road-cross:srd` | 无 | 绘制道路（键盘输入宽度） |
| `road-cross:sld` | 无 | 画线补路 |
| `road-cross:std` | 无 | 设置倒圆角和误差值参数 |
| `road-cross:help` | 无 | 显示帮助信息 |
| `Draw_the_road` | 无 | 道路绘制主程序 |

## 依赖

- **base** - @lisp 基础包

## 功能说明

- **绘制道路1 (rd)**: 通过鼠标点击两点确定道路宽度，然后绘制道路
- **绘制道路2 (srd)**: 通过键盘输入道路宽度，然后绘制道路
- **画线补路 (sld)**: 在既有道路上画一条线，自动获取道路宽度并补上新路
- **容差设定 (std)**: 设置倒圆角值和寻找道路宽容许误差
