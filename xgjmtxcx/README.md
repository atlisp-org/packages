# xgjmtxcx - 型钢截面特性查询

型钢截面特性查询工具。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 结构 > 型钢截面特性 | `(xgjmtxcx:open)` | 启动型钢截面特性查询工具 |

## 源文件

| 文件 | 说明 |
|------|------|
| `xgjmtxcx.lsp` | 主程序，启动外部 EXE 工具 |

## 依赖

- `base`

## 配置

无配置项。首次运行会自动下载 EXE 文件。

## 安装

在 CAD 命令行执行：
```
@I xgjmtxcx
```
