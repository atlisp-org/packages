# youyun-plot - 有云批量打印

有云批量打印工具，PDF1 v3.4.9 版本。作者：紫神炒黄瓜。

## 菜单命令

| 菜单 | 命令 | 说明 |
|------|------|------|
| 出图排版 > 有云批打 | `(youyun-plot:bplot)` | 启动有云批量打印 |

## 源文件

| 文件 | 说明 |
|------|------|
| `youyun-plot.lsp` | 主程序，初始化环境并加载批量打印 |
| `youyun-plot.zip` | 完整安装包 |

## 依赖

- `base`

## 配置

无配置项。

## 使用说明

1. 首次运行会自动创建目录链接和解压文件
2. 自动下载 pdftk 工具
3. 加载有云批量打印 VLX 模块

## 安装

在 CAD 命令行执行：
```
@I youyun-plot
```
